# SportPlanner — Проект

## Что это
Веб-приложение для подготовки к Московскому марафону 2027 (цель <3:15:00). 52-недельный план тренировок с AI-тренером, логированием и прогнозом марафонского времени.

**Живой сайт:** https://sportplanner-run.surge.sh/
**GitHub:** https://github.com/uhizugok018-star/sp-app (чистый деплой)
**GitHub (разработка):** https://github.com/uhizugok018-star/sportplanner

## Технологии
- **Стек:** vanilla HTML + CSS + JS (без фреймворков, без сборки)
- **Хранение данных:** `localStorage` (ключ `sportplanner_v1`)
- **AI:** ЯндексGPT через Cloud Function прокси (обходит CORS)
  - Cloud Function URL: `https://functions.yandexcloud.net/d4ekootniaavna0632t9`
  - Рантайм: Python 3.12
  - Проксирует запросы к `llm.api.cloud.yandex.net/foundationModels/v1/completion`
  - Ключ API передаётся как Bearer-токен (только секретная часть, без ID)
  - Поле для сообщений: `messages` (НЕ `completionMessages`)
  - OpenRouter тоже поддерживается в коде, но заблокирован из РФ
- **Деплой:** Surge.sh (`sportplanner-run.surge.sh`)
  - GitHub Pages сломался (builds постоянно errored)
  - Surge работает стабильно

## Важные находки при разработке
1. **YandexGPT API принимает `messages`, а НЕ `completionMessages`** — поле было переименовано
2. **API-ключ передаётся как только секрет (без ID)** — формат `Bearer AQVN...`, а не `Bearer ajei...:AQVN...`
3. **CORS:** Yandex API не поддерживает CORS → решено через Cloud Function прокси
4. **GitHub Pages:** builds постоянно errored для аккаунта `uhizugok018-star` (причина неизвестна)
5. **Surge.sh:** работает стабильно, бесплатный, без регистрации (npx surge)
6. **GitHub PAT:** нужны scopes `repo` + `workflow` для полного доступа. Без `workflow` нельзя пушить `.github/workflows/`
7. **OpenRouter:** заблокирован из РФ (IP block)

## PWA
- Service Worker кеширует все файлы приложения
- API-запросы к Yandex Cloud Function идут напрямую (не кешируются)
- Установка на телефон: Safari → «На экран Домой» (iOS) / Chrome → ⋮ → «Добавить на главный экран» (Android)

## Что умеет приложение
1. **План тренировок** — 52 недели (4 блока: база, накопление, соревновательный, старт)
2. **Логирование** — дистанция, время, темп, пульс, RPE, погода, заметки
3. **3 режима отображения** — «Сегодня», «Неделя», «Весь план» (pinch-zoom)
4. **AI-тренер** — анализ плана и фактических результатов, корректировки
5. **Прогноз марафона** — формула Ригеля
6. **Авто-корректировки** — перенос пропущенных, сдвиг темпов
7. **Экспорт** — выгрузка в JSON
