# SportPlanner — Проект

## Что это
Веб-приложение для подготовки к Московскому марафону 2027 (цель <3:15:00). 52-недельный план тренировок с AI-тренером, логированием и прогнозом марафонского времени.

**Живой сайт:** https://uhizugok018-star.github.io/sportplanner/

## Технологии
- **Стек:** vanilla HTML + CSS + JS (без фреймворков, без сборки)
- **Хранение данных:** `localStorage` (ключ `sportplanner_v1`)
- **AI:** прямые API-запросы из браузера (без бэкенда)
  - OpenRouter (бесплатные модели Llama/Mistral/Gemma/Qwen)
  - ЯндексGPT (по IAM-токену)
- **Деплой:** GitHub Pages (репозиторий `uhizugok018-star/sportplanner`)

## Структура файлов
```
index.html       — весь UI (модалки, стили, разметка)
app.js           — вся логика (~995 строк)
manifest.json    — PWA-манифест
sw.js            — Service Worker (оффлайн-кеш)
icon-192.svg     — иконка 192×192
icon-512.svg     — иконка 512×512
```

## PWA
- Service Worker кеширует все 5 файлов приложения
- API-запросы к OpenRouter/Yandex идут напрямую (не кешируются)
- Установка на телефон: Chrome → ⋮ → «Добавить на главный экран» (Android) / Safari → «На экран Домой» (iOS)
- Работает оффлайн (кроме AI-запросов)

## Что умеет приложение
1. **План тренировок** — 52 недели (4 блока: база, накопление, соревновательный, старт)
2. **Логирование** — дистанция, время, темп, пульс, RPE, погода, заметки
3. **3 режима отображения** — «Сегодня», «Неделя», «Весь план» (переключение свайпом pinch-zoom)
4. **AI-тренер** — анализирует план и фактические результаты, предлагает корректировки
5. **Прогноз марафона** — формула Ригеля на основе последних результатов
6. **Авто-корректировки** — перенос пропущенных тренировок, сдвиг темпов при систематическом отклонении
7. **Экспорт** — выгрузка всех данных в JSON
